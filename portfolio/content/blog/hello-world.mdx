Welcome to the blog. Every post on this site is a plain **MDX** file in `content/blog/`.

## How publishing works

1. Create a new `.mdx` file in `content/blog/`.
2. Add `title`, `date`, `description`, `slug`, and `tags` frontmatter.
3. Commit — the page is statically generated at build time.

> No CMS, no database. Just files.

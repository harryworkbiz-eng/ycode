The homepage hero renders a small **react-three-fiber** scene. WebGL bundles are heavy,
so the scene is loaded with `next/dynamic` and `ssr: false`.

```tsx
const HeroScene = dynamic(() => import("./HeroScene"), { ssr: false });
```

The rest of the page renders immediately; the canvas fades in once the bundle arrives.

A minimal, typography-first portfolio.

## Stack

- Next.js App Router with static generation
- Tailwind CSS with the typography plugin
- react-three-fiber hero scene, loaded client-side only
- MDX files in `content/` parsed with `gray-matter` and rendered with `next-mdx-remote`
